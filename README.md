# ArXiv-ML Research Assistant (RAG-система)

Локальна система генерації, доповненої пошуком (Retrieval-Augmented Generation, RAG),
призначена для семантичного пошуку та узагальнення наукових анотацій arXiv
у категорії `cs.LG` (Machine Learning) через інтерфейс командного рядка (CLI).

## Сценарій використання
- **Цільовий користувач:** магістрант або інженер-дослідник у галузі ML/SE,
  який виконує огляд сучасної наукової літератури.
- **Корпус даних:** 5 000 анотацій arXiv (`cs.LG`, 2024–2025 рр.), ліцензія CC0 1.0.
- **Очікуваний результат:** лаконічна обґрунтована відповідь із валідними цитатами
  ідентифікаторів джерел або коректна відмова за відсутності даних у корпусі.

## Технологічний стек
- **Мова програмування:** Python 3.11+
- **Векторне сховище:** ChromaDB (локальний персистентний режим)
- **Модель ембедингів:** `sentence-transformers/all-MiniLM-L6-v2` (CPU, 384-d)
- **Модель генерації:** Ollama (`llama3.2:3b`, локально)

## Встановлення та налаштування середовища

1. Клонування репозиторію:
   ```bash
   git clone https://github.com/<username>/rag-project-hmyrak.git
   cd rag-project-hmyrak
   ```

2. Створення та активація віртуального середовища Python:
   ```bash
   python -m venv .venv
   # Windows (PowerShell):
   .venv\Scripts\Activate.ps1
   # Linux / macOS:
   source .venv/bin/activate
   ```

3. Встановлення залежностей Python:
   ```bash
   pip install -r requirements.txt
   ```

4. Встановлення Ollama та завантаження локальної LLM:
   Завантажте Ollama з https://ollama.com/ та виконайте команду:
   ```bash
   ollama pull llama3.2:3b
   ```

## Структура проєкту
- `src/` — вихідний код пайплайнів прийому даних, індексування, пошуку та CLI.
- `config/` — YAML-конфігурація параметрів системи.
- `reports/` — звітна документація за лабораторними роботами (`lab-1` .. `lab-5`).
- `tests/` — оцінювальні набори (`eval-set.jsonl`, `gold-set.jsonl`) та автотести.
